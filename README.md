# SystemInfoApp (Kotlin) - Minimal project
Это минимальный Android-проект на Kotlin, показывающий характеристики устройства (вкладки: CPU, Память, Батарея, Камера, Сенсоры, Сеть).

## Как использовать
1. Скачай и распакуй этот архив.
2. Открой проект в Android Studio (File -> Open -> выбери папку `system_info_app`).
3. Подожди, пока Gradle синхронизируется. Затем запусти на устройстве или эмуляторе.

Если у тебя нет компьютера:
- Можно импортировать Kotlin-проекты в **AIDE** (в Android) — потребуется адаптация Gradle, но файлы `app/src/main` можно использовать.
- Другой вариант — создать репозиторий на GitHub и настроить GitHub Actions для сборки APK (я могу подсказать workflow).

## Ограничения
- На Android 10+ некоторые поля (MAC-адреса, SSID) могут требовать дополнительных разрешений или быть недоступны.
- Код предназначен как шаблон — можно улучшать UI, обработку ошибок и запросы runtime permissions.
